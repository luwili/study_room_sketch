Электронный учебный кабинет и интерактивный портал для студентов группы **ПОНБ-УП-304С** специальности 40.05.01 «Правовое обеспечение национальной безопасности» (уголовно-правовой профиль) **Института права Уфимского университета науки и технологий** (г. Уфа).

- **Опубликованный сайт:** [https://luwili.github.io/study_room_sketch/](https://luwili.github.io/study_room_sketch/)
- **Репозиторий проекта:** [https://github.com/luwili/study_room_sketch](https://github.com/luwili/study_room_sketch)
- **Город и часовой пояс:** г. Уфа, Республика Башкортостан (`Asia/Yekaterinburg`, UTC+5)
- **Куратор группы:** ст. преподаватель кафедры уголовного права и процесса Нурмухаметов Руслан Наилевич

---

## 🎨 Дизайн-система «Футуристичный рисованный скетчбук»

Визуальный облик портала спроектирован в концепции технологичного студенческого скетчбука:
- **Цветовая палитра**: тёплая бумага (`#FAF8F3` / тёмный чернильный `#0D121D`), чертёжная миллиметровая сетка (blueprint grid), электро-индиго (`#2563EB`) и акцентный кибер-лайм маркера (`#84CC16`).
- **Ручная геометрия**: сглаженные «неровные» контуры (`rounded-sketch-*`), жёсткие смещённые тени (`shadow-sketch`: `3px 3px 0px #12161A`).
- **Авторский маскот**: интерактивный SVG-символ **«Orbit Pencil»** (орбитальный карандаш с академическим академическим спутником).
- **Типографика и акценты**: гарнитура `Anthropic Serif Web`, моноширинные технические бейджи, маркерные выделители и штампы.
- **Анимации и доступность**: плавная реакция на hover, staggered-появление карточек, поддержка `prefers-reduced-motion`.

## 🌟 Разделы и возможности

1. **Главная (Информационная панель)**:
   - Live-индикатор времени г. Уфы (`Asia/Yekaterinburg`, UTC+5).
   - Динамический статус учебной пары («Идёт сейчас», «Перемена», «Пары завершены»).
   - Расписание на сегодня с аудиториями и преподавателями.
   - Закреплённые объявления и фильтрация по тегам.
   - Баннер загрузки виджета для Android с быстрой deeplink-синхронизацией.

2. **Расписание занятий (17 недель / 245 пар)**:
   - Селектор недель 1–17 с индикатором чётности/нечётности (знаменатель/числитель).
   - Дневной переключатель (Пн–Сб).
   - Официальные звонки Института права УУНиТ для 1-й и 2-й смен.
   - Карточки занятий: форма (лекция/семинар), аудитории (ул. Достоевского, 131), преподаватель.

3. **Дисциплины (10 предметов)**:
   - Уголовный процесс, Уголовное право, Финансовое право, Гражданский процесс, Административный судебный процесс, Гражданское право ч.2, Экологическое право, Спецподготовка, Финграмотность, ОФП.
   - Фильтрация по экзаменам, диф. зачётам и зачётам.
   - Раскрывающиеся списки тем и привязка к кафедрам.

4. **Темы и конспекты**:
   - Переключение: «Полный конспект» (с разбором доктрины) ↔ «Краткий для записи» (тезисы для семинара).
   - 3 режима масштабирования шрифта, плавающее оглавление (TOC), нормативная база.
   - Поддержка чистой печати конспектов без интерфейсных элементов (`Ctrl+P`).

5. **Подготовка к экзаменам**:
   - Сводка экзаменов и зачётов группы.
   - Двусторонние 3D флэш-карточки («Знаю» / «Повторить»), перемешивание (Shuffle), сохранение прогресса в `localStorage`.
   - Полный банк экзаменационных вопросов по дисциплинам.

6. **Справочник преподавателей (120+ персоналий)**:
   - Фильтр: «Преподаватели группы» и «Все преподаватели института».
   - Модальные досье с контактами, курсами и часами консультаций.
   - Полноэкранный Lightbox для просмотра фото преподавателей.

7. **Кафедры Института права (8 выпускающих кафедр)**:
   - Руководство, кабинеты на ул. Достоевского 131, служебные телефоны и почта.

8. **Институт права и полезные ссылки**:
   - Адреса корпусов (ул. Достоевского, 131 и ул. Заки Валиди, 32).
   - 9 официальных разделов портала `law-bsu.ru` (заказ справок, практика, расписания).
   - Государственные правовые порталы: pravo.gov.ru, КонсультантПлюс, Гарант, СудАкт, ВС РФ.

9. **Персональные закладки**:
   - Быстрый доступ к сохранённым лекциям с расчётом времени чтения.

10. **Глобальный поиск (`Ctrl+K`)**:
    - Моментальный поиск по дисциплинам, конспектам, преподавателям и кафедрам с нормализацией буквы «ё».

11. **Виджет для Android (APK v1.2.0)**:
    - Независимый домашний виджет для телефонов Samsung, Xiaomi, Pixel.
    - Передача расписания прямо из браузера в 1 клик (`studyroom://sync?data=...`).

## 🚀 Быстрый старт и локальный запуск

### 1. Требования к окружению
- **Node.js**: версии 18, 20 или 22+
- **npm**: 9+

### 2. Установка зависимостей
```bash
git clone https://github.com/luwili/study_room_sketch.git
cd study_room_sketch
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
Сервер будет доступен по адресу `http://localhost:5173`.

### 4. Проверка типов и сборка дистрибутива
```bash
npm run check
npm run build
```
Готовая статическая сборка будет сгенерирована в директорию `dist/`.

### 5. Предпросмотр сборки
```bash
npm run preview
```

## 📦 Сборка и деплой на GitHub Pages

Проект настроен для полностью автоматического деплоя на **GitHub Pages** через GitHub Actions ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)):
- Относительный базовый путь (`base: './'`) в `vite.config.ts` обеспечивает корректную загрузку ассетов в подпапке репозитория.
- Роутинг на основе хэша (`#/schedule`, `#/topics`) исключает ошибки 404 на статических серверах без перенаправлений.
- Workflow автоматически собирает статический билд и публикует его в ветку `gh-pages` / GitHub Pages Environment при каждом пуше в `main`.

## 🔒 Безопасность и конфиденциальность

- В репозитории **отсутствуют** секретные API-ключи, токены и приватные переменные окружения.
- Персональные данные студентов (номера зачёток, баллы, личные номера) исключены из сборки и добавлены в `.gitignore`.
- Шаблон переменных для локальной синхронизации вынесен в `.env.example`.
